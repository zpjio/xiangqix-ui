## 一、 整体布局与信息架构

应用采用桌面级单屏无滚动条布局（`100vh × 100vw`，`overflow: hidden`），由上至下分为三层结构：

1. **顶部导航栏（Titlebar）**
   - **左区**：品牌印记（「象棋X」，点击回到「复盘分析」）。
   - **中区**：五大核心工作空间导航（按「核心枢纽 → 开残专项 → 对战 → 工具」排布）——`复盘分析 (study)`、`开局研习 (opening)`、`残局题库 (challenge)`、`人机对弈 (play)`、`摆子编辑 (setup)`，支持 `⌘K` 面板快捷键 `1 ~ 5` 快速切换。
   - **右区（业务分组 | 系统工具）**：左侧业务组按数据生命流排布——`导入 / 导出`（双页签弹窗：`导入至复盘` 支持 FEN、完整中文纵线 PGN 还原与图片识盘，导入统一进入 `复盘分析`；`分享与导出` 左栏实时预览并导出 **`1080×1400` 高清棋盘战报图 `.png`**——含当前棋盘/主题工艺、右键手绘标注箭矢/圆圈、路数坐标、净多子力及红黑对局信息，支持下载或一键复制到剪贴板；右栏支持 **无损分享直链 (`#share=...`) 复制**、当前盘面 `.fen`、标准 PGN 及微信纯中文棋谱导出，并可选附带引擎评分与批注）、`棋谱库 (含实时总谱数统计)`、`连线`（连接成功自动切入 `复盘分析`）；以 `1px` 竖线分隔右侧系统组——`命令面板 (⌘K，含 F 导入 / E 分享导出 / N 路数坐标开关 / T 循环切主题 / Y 直达温润护眼快捷键)`、`音效开关`、`三态护眼主题循环（深色夜案 → 清朗浅色 → 温润护眼）`、`设置中心`（支持三态分段切换与棋盘路数坐标开关）。
2. **主工作台（Main Stage + Right Sidebar）**
   - **左侧主画布区（~62% 黄金比例主视角，启用 `container-type: size`）**：上方极简无边框棋手条（`PlayerSeatBar`，摆子模式隐藏，展示净多子力微缩圆章与净分差，在 `play` 对弈且启用包干加秒时右对齐展示红/黑包干倒计时与超时警戒）+ 胜率评估柱（`EvalBar`，仅复盘分析模式显示）+ 9×10 容器自适应棋盘（`Board`，放宽至最高 `820px` 并保留微距呼吸边，支持默认开启可开关的上下路数坐标 `九~一 / 1~9`、点选与拖拽走子、FLIP 棋子平滑滑移、右键 4 色战术画线/标圈、非阻塞 60 回合/三次重复/双方无进攻子力死和判和提示条、单方长将违例警示/退回变着条及 9 类终局卡片，终局卡片同步提供一键「分享战报」直达导出弹窗）+ 下方极简无边框棋手条 + 棋盘操控底栏（`BoardNav`，存在手绘箭头/标圈时动态呈现 `清标注` 按钮，避免棋盘内浮层遮挡边角棋子）。
   - **右侧工作台（约 `37.5%~39.5%` 黄金比例，`390px ~ 600px` 随全局字号自适应微调，支持折叠/展开）**：根据当前工作空间动态渲染对应模块；UI 层全面采用基于根字号（标准 `100% / 16px`、大 `112.5% / 18px`、特大 `125% / 20px`）的 `rem` 排版体系（次要说明下限 `12px`，棋谱/引擎候选正文 `13px~14px`）。
3. **底部状态栏（StatusBar）**
   - 实时展示当前工作空间任务提示（含开局变例对练实时步序提示、人机执红/执黑与本地双人对弈模式提示）、非法应将/送将瞬时警告、子力净分差、当前行棋方、步数（`当前手/总手数`）、长捉/限着预警指标（当连续非将军无吃子接近或达到 `60` 回合时显示 `无吃子 X/60`，同一局面重复 `>= 2` 次时显示 `重复 X/3`，若为单方连续长将循环则升级显示 `{红方/黑方}长将禁止`，双方无进攻子力时显示 `双方无进攻子力`）、将军告警（`红帅受将 / 黑将受将`）及 9 类终局徽章（`红胜 · 绝杀 / 黑胜 · 困毙 / 和棋 · 60回合 / 和棋 · 三次重复 / 和棋 · 死和 / 双方协议和棋 / 长将判负 / 认负 / 超时判负`）。

## 二、 首次启动与持久化策略

1. **冷启动与直链还原策略**
   - 首次进入默认打开 `复盘分析 (study)`，棋盘展示 **32 子标准开局**（红方先行，手数 `0`），不再自动灌入虚构演示残谱，避免误导用户。
   - **URL 分享直链冷启动还原（`#share=...`）**：若访问 URL Hash 携带 `#share=` 编码载荷（由 `buildShareUrl` 生成，包含 `baseFen`、紧凑 `from/to` 着法序列、`currentPly`、棋盘方向 `flipped` 与元数据），应用冷启动优先解析并无损还原至对应对局的 `study` 复盘工作台、历史手数与朝向；挂载后通过 `window.history.replaceState` 清理 URL Hash 防止误刷新重复覆盖本地编辑（若载荷校验失败则给出柔和提示并回退至本地复盘工作台）。
   - **空谱快捷引导**：当 `mainMoves.length === 0` 时，右侧「回合棋谱」与「复盘报告」页签分别提供引导卡片，支持一键：
     - `载入示范名局`（加载预置 12 手经典名局供体验）；
     - `开局定式`（一键切换至右侧「定式查询」轻查询页签或进入独立「开局研习」工作台）；
     - `导入 FEN / 识盘`（打开导入/图片识别弹窗）；
     - `打开棋谱库`（浏览历史、现代名局、古谱与自存对局）。
2. **本地持久化（`localStorage`）**
   - **复盘会话 (`xiangqix_study_session_v1`)**：仅当 `workspace === 'study'` 时自动保存，包含当前盘面 `pieces`、基准起点盘面 `basePieces`、基准先行方 `baseTurn`、主谱 `mainMoves`（含每手 `nag` 棋评符号与 `comment` 手写批注）、支线 `variationMoves`、分叉点 `branchOriginPly`、当前手数 `currentPly`、当前行棋方 `turn`、对局元数据 `metadata`、关联棋谱库 ID `activeLibraryGameId`、棋盘翻转状态 `flipped`。为避免快速步进或自动回放期间频繁同步序列化阻塞主线程，写入采用 **`350ms` 防抖调度**，并在切换离开 `study` 工作台、触发 `pagehide` / `beforeunload` 或组件卸载时立即同步落盘。
   - **本地棋谱库 (`xiangqix_library_v1`)**：保存预置名局、古谱及用户通过「存局」写入的 `LibraryGameItem[]`（含 `baseFen` 与紧凑着法数组 `movesData: CompactLibraryMove[]`，完整保留每手 `nag` 与 `comment`），采用 `300ms` 防抖落盘。
   - **残局破关进度 (`xiangqix_challenges_solved_v1`)**：持久化用户已破关的 `challengeId[]`，支撑顶栏总进度与「仅看未破」筛选。
   - **全局偏好 (`xiangqix_prefs_v1`)**：保存主题、字号、音效、棋盘/棋子工艺、简繁字形、棋盘路数坐标显示开关 `showBoardCoordinates`（默认 `true`）、主/副引擎 ID、双擎对比开关、MultiPV 条数、深度、线程数、Hash 内存及人机棋钟赛制 `clockPresetId` 等配置。
   - **按需延迟初始化**：示范名局棋谱、开局库盘面指纹索引图与当前盘面 FEN/PGN 导出字符串均采用惰性按需生成，不在冷启动或无弹窗常规走子渲染期间预先计算。

## 三、 五大工作空间详细交互逻辑

### 1. 复盘分析 (`study`) — 引擎研习与轻定式查询枢纽
- **引擎分析舱（`EnginePanel`）**：
  - **单按钮主控**：顶栏左上角仅保留唯一切换开关——未运行时为 **「开始分析」**，运行中为 **「暂停分析」**；待机区仅展示就绪提示文本，无重复按钮。
  - **引擎切换与安装引导**：支持切换预置引擎（`皮卡鱼 UCI`、`旋风 UCI`、`天机 UCCI`）或自定义导入引擎；若引擎状态为 `missing`，主体区替换为组件缺失提醒 + NNUE 权重说明 +「一键下载安装」与「引擎库管理」入口；安装中展示三阶段进度条并在完成后自动进入分析。
  - **双擎对比模式（`compareMode` / 快捷键 `C`）**：
    - 开启后在顶栏下方常驻 **对称配对条**：`主 [引擎A ▾] ⇄ 副 [引擎B ▾]`。
    - 选择冲突自动处理：若主副选到同一引擎，自动将另一槽位对调互换；点击中间 `⇄` 按钮可一键互换主副引擎。
    - 主副对比结果：顶栏输出「**双擎共识**（绿色，一致首推某着 + 分差 Δ）」或「**双擎分歧**（琥珀金，分别标出主/副主推着法 + 分差 Δ）」；棋盘上以翠绿（`#10B981`）与天青蓝（`#3B82F6`）区分主副箭头，共识时合并为 `[双擎共识]` 箭头。
  - **多主变（MultiPV）与威胁雷达**：
    - 悬停候选着法行，棋盘渲染金色半透明幽灵预览箭头；点击候选着法直接在棋盘上试走并进入分支。
    - 开启「威胁」按钮后，棋盘以红色虚线箭头标出对方下一步最具威胁的攻着。
- **连续双栏棋谱（`MoveList`）、单手棋评批注与存局导出**：
  - 按回合（红方 + 黑方）双栏展示着法、棋评符号（`!! / ! / !? / ?! / ? / ??`）、质量角标（`妙/优/良/缓/败`）、红方视角分值（`+0.45` / `-1.20`）及批注气泡图标；导出 PGN / 微信纯中文棋谱时 **手写 `nag` 与 `{comment}` 默认永久保留**（仅将注释内容中的 `{`/`}` 清洗为 `(`/`)` 防语法截断），勾选「附带引擎评分与评级」时同步追加引擎 `{评:...}` 信息。
  - 棋谱列表下方（`currentPly > 0` 时）内嵌 **单手批注编辑条**：点击快捷开关即可为当前着法（支持主谱或超支线回退兜底）点选 `!!` ~ `??` 棋评符号（再次点击取消）并撰写文字批注，支持 `Ctrl/⌘+Enter` 快捷保存或清除。
  - 对局信息头提供主次分明的 **「存局 / 更新存局」**、**「★ 星标收藏」** 与 **「导出」** 快捷操作：「存局」为主保存入口（拦截「32 子标准开局 0 手」空盘存局，将 `baseFen` 与含 `nag / comment` 的完整着法写入或原地更新「自存对局」）；「★」定位为**独立收藏状态开关**；对局双方姓名支持点击直达「编辑对局信息」并附带显式编辑徽标与 Tooltip 引导。
  - 在任意历史手（`currentPly < mainMoves.length`）直接走棋或点击引擎候选着，若与主谱下一步不同，立即从该手分叉生成 **内联推演支线**（棋盘框呈现金边高亮并标出「推演分支中」，支线芯片亦透出自身 `nag` 与批注角标）。
  - 支线顶部内嵌操作条支持：**「升为主线」**（替换主谱后续着法）或 **「返回主谱」**（丢弃支线回到分叉手）。
- **棋盘操作质感与战术画线标注（全工作空间通用）**：
  - **点选 + 鼠标/触控板拖拽走子**：按住己方棋子移动超过 `6px` 进入流畅跟随拖拽状态并点亮合法落点（启用 `touch-none` 防止触控滚动抢占）；拖拽落子后通过 `justDraggedRef` 短暂抑制释放后的重复 click 触发。
  - **FLIP 平滑滑移（`transform` GPU 合成）**：无论点选、拖拽、AI 应手还是步进跳手，位置变化均通过前帧→后帧坐标差计算实现约 `185ms` `cubic-bezier(0.22, 1, 0.36, 1)` 棋子滑移；正在拖拽释放的一手直接跳过二次滑移防回弹；棋盘翻转或换局切换自动重置快照不乱飞。
  - **右键四色战术画线与标圈**：在盘面右键单击交点切换高亮圆圈，右键拖拽至另一交点切换战术箭头；默认金色（`gold`），支持 `Shift`（翡翠绿 `jade`）、`Alt`（天青蓝 `azure`）与 `Shift+Alt`（朱红 `crimson`）切换四色方案；在棋盘空白交点（无箭头与标圈）或新局面/点击底栏 `清标注` 时干净清空，不在棋盘四角叠加会遮挡边车/底士卒的悬浮按钮。
  - **60 回合无吃子（扣减将军）、三次重复、单方长将与死和判定**：由 `computeDrawRuleStatus` 实时跟踪无吃子半步数（扣减红黑将军拍子，达 `>=120` 即 60 回合）、同形循环次数（达 `>=3` 次，且在三次重复区间内识别是否存在单方连续每步将军的长将违例 `perpetualCheckCamp`）及双方无进攻子力死和（无车/马/炮/兵卒时 `canClaimInsufficientDraw = true`）。
    - 当发生单方长将（`perpetualCheckCamp !== null`）时：禁止按普通三次重复判和，在分析/研习/题库模式顶部弹出朱红违例警示条（支持「退回变着」回退 1 手或「忽略」）；
    - 当满足 60 回合无吃子、普通三次重复或双方无进攻子力死和时：在棋盘顶部弹出**非阻塞判和浮动条**（内设 `e.stopPropagation()` 防穿透落子），支持「判和 / 立即判和」或「暂不判和继续」。
- **整局复盘报告（`GameReviewPanel`）**：
  - 红黑双方精准度百分比基于当前主谱各手 `quality` 标签实时加权计算（`妙=99, 优=95, 良=88, 缓=74, 败=48`），不再写死固定数值。
  - 内嵌局势演化曲线（`EvalGraph`），支持点击任意手跳步。
  - 自动筛选 `缓 / 败` 着生成 **关键失误诊断卡片**，点击 **「在此手重练」** 自动跳回失误前一手并要求用户在棋盘走出正确着法，系统实时判对错。
- **常驻实时定式识别条与「定式查询」轻页签**：
  - 在 `study` 右侧三页签栏（`回合棋谱 | 复盘报告 | 定式查询`）下方常驻单行 **实时定式识别条**（`定式 [当前定式名] · 同开局名局 (N) · 去精练 →`）：无论用户当前停留在哪个页签，均可实时感知盘面所属定式；点击定式名直达「定式查询」页签，点击 `同开局名局 (N)` 直接以 `matchKeyword` 预筛选打开「棋谱库」弹窗，点击 `去精练 →` 携带当前开局步数一键切入独立「开局研习」工作台。
  - **「定式查询」轻页签（`<OpeningBookPanel mode="compact" />`）**：仅保留随盘面 O(1) 实时匹配、着法面包屑、流行后续变例统计（支持悬停预览幽灵箭头与点击直接走入分支）、脱谱回溯及底部 **`前往「开局研习」精练本体系 →`** 入口；完整的体系探索树与防剧透变例对练功能收口至顶栏独立「开局研习」工作台，保持复盘侧栏轻量专注。
  - 棋谱库弹窗内部亦提供定位说明横幅（「棋谱库存整局名局 · 开局研习查定式与对练」）及 `打开开局研习 →` 双向跳转入口，明晰两库互补关系。

### 2. 开局研习 (`opening`) — 独立定式树与变例防剧透对练工作台
- **独立会话隔离与纯净防剧透布局**：
  - 切换至 `opening` 时盘面与 `study` 的 `xiangqix_study_session_v1` 完全隔离，在开局树自由探索、回退或开启变例对练不会误覆盖用户在「复盘分析」中的进度；若从「复盘分析」点击 `去精练 →` / `前往「开局研习」精练本体系 →` 且当前为标准开局起点，系统会自动携带当前已走着法切入对应定式节点。
  - 隐藏 `EnginePanel`、`EvalBar`、MultiPV 与威胁雷达箭头，避免引擎推荐着剧透对练记忆；上下棋手席位条展示「开局定式研习 / 变例对练执红(或执黑) + 当前定式名」。
- **双态完整工作台（`<OpeningBookPanel mode="full" />`）**：
  - **定式树 (`explorer`)**：
    - 顶部展示可点击跳手的 **着法路径面包屑**（点击任意历史手或「初始」即刻跳回对应定式分叉点）。
    - 随当前盘面实时计算 **盘面指纹（`piecesPlacement + turn`，兼容同形换手/变序还原）** 进行 O(1) 定式匹配；已命中节点展示定式名称、所属体系、样本量、棋理短评与 `查同局谱 (N) →` 直达按钮；下方按出现频率降序展示流行后续着法（标注 `陷阱/激烈/主流/古谱/稳健` 语义提示与红胜/和/黑胜比例条），悬停预览金色幽灵箭头、点击走入分支。
    - 底部提供体系分类过滤（`全部 / 中炮 / 仙人指路 / 飞相局 / 起马局`）及 **7 套主流开局定式骨架**，每套同时提供「载入」与「对练」快捷按钮；脱谱后保留最后命中定式回溯按钮与同体系棋谱库入口。
  - **变例对练 (`drill`)**：
    - 支持选择 **「执红先手练」** 或 **「执黑后手练」**（执黑时自动翻转棋盘并在 `450ms` 后模拟对方走出先手首招）。
    - 进入对练（`status === 'drilling' | 'mistake'`）时隐藏底栏自动回放按钮，屏蔽 `Space` 快捷键，仅保留「提示此步 / 在棋盘提示正着」与底部「支招」供主动求助。
    - 每次落子在 `executeMoveOnBoard` 中实时校验：正着则推进步序并在 `450ms` 后自动走入对手应手；错着则停留在决策前局面并提示偏离定式、累计失误次数；走完末手后结算一次命中率并持久化至 `xiangqix_opening_drills_v1`。
- **底部主按钮**：固定展示 **「携带当前定式转入复盘分析」**（或有实战手数时显示 `携带 N 手定式转入复盘分析`），点击后将当前开局盘面与着法交接至 `study` 开启 Deep Engine 深度剖析。

### 3. 残局题库 (`challenge`) — 规模化题库检索与破局闯关
- **纯净防剧透布局**：隐藏引擎分析舱与左侧评估柱；棋盘上下席位条展示「挑战者（红方）」vs「古谱出处（如《百局象棋谱》《适情雅趣》）」。
- **右侧可规模化题库工作台（`ChallengeWorkbench`）**：
  - **破关总进度**：顶栏固定展示 `已破关 X / Y 关 · Z%` 及完成度进度条（持久化至 `xiangqix_challenges_solved_v1`）。
  - **多维检索筛选**：支持关键字搜索（残局名称/典籍/杀法说明）、古谱典籍下拉筛选（`百局象棋谱`、`心武残编`、`橘中秘`、`适情雅趣`、`竹香斋`、`梦入神机`）、难度分段筛选（`全部 / 进阶 / 高难 / 绝杀`）及 **「仅看未破」** 开关，当前内置 **12 道坐标核验经典残局** 并面向百关级扩展设计。
  - **精简卡片与手动核销**：每关卡片以 `典籍 · 难度 · 约 N 手杀` 纯文本无胶囊排版呈现，支持点击「待破 / 已破关」状态核销；重摆与支招仍统一收敛至棋盘底栏不重复。
- **自动应手、破关判定与支招**：
  - 玩家执红走子后，系统评估第 1 手是否命中预置正着（或后续走至大优胜势 `eval >= +5.0`）并自动标记该关为 **「已破关」**，随后延迟约 `620ms` 模拟黑方自动应手。
  - 点击底栏 `支招`：若在残局第 0 手，优先亮出古谱预置正着箭头与文字解析；若已走入变例，则调用引擎计算当前最佳应对。
- **底部主按钮**：固定展示 **「转入复盘分析」**（若已试走着法，文案自动显示为 `携带 N 手试走转入复盘分析`）。

### 4. 对弈实战 (`play`) — 人机自选执方 + 本地双人面对面
- **纯净实战布局**：隐藏引擎分析舱与左侧评估柱；席位条按模式精准显示「玩家（红方/黑方） vs 电脑引擎（含让子标签）」或「红方棋手 vs 黑方棋手 · 本地双人」，当棋钟启用时右上角/右下角席位条同步显示剩余用时（不足 `30s` 琥珀/朱红警戒闪烁；最后 **`10s`** 每跨过整秒触发 `playClockWarningTickSound` 滴答提醒，遵守全局 `soundEnabled`、暂停与弹窗遮罩冻结约定）。
- **右侧对弈面板**：
  - **对战模式与执方 (`PlayOpponentMode` + `playHumanCamp`)**：
    - **`人机对弈 (ai)`**：支持自选 **「我方执红（先手）」** 或 **「我方执黑（后手）」**。切换为「我方执黑」时棋盘自动翻转使黑方居下，并适配红方让左马/让双马（`createInitialPieces(handicap, concededBy)`）及分先由电脑先行走出红方第 1 手；
    - **`本地双人对弈 (local-pvp)`**：同屏面对面红黑轮流走子，关闭 AI 自动应手并按双方共享棋钟与棋规裁判裁决，支持单手渐进悔棋（1 步）、双方协议和棋（「双方议和」）与当前行棋方认输（「红方/黑方认输」）。
  - **包干加秒棋钟赛制 (`CHESS_CLOCK_PRESETS`)**：支持 **`不限时 (none)`**、**`快棋 5+3 (blitz-5-3)`**、**`常规 10+5 (rapid-10-5)`**、**`慢棋 20+10 (classical-20-10)`** 四档包干加秒，配置持久化至全局偏好；首步落子后计时器自动起表，每次双方合法走子后为走子方加秒（`+incrementMs`），最后 10 秒逐秒低时提示音，支持「暂停/继续计时」及超时自动按 `timeout` 判负。**注：棋钟倒计时仅作用域收敛在 `play` 工作台，不在 `study` 复盘研习时倒计时误判超时。**
  - **开局让子与先手**：`分先`（双方满子红先）、`让先`（双方满子黑先——当 AI 执该先手方时由 `schedulePlayBotMove` 自动触发首手应手）、`让左马` / `让双马`（人机执黑时由红方电脑撤马让子，其余由黑方撤马）。
  - **电脑棋力档位与开局随机变化 (`selectBotPlayMove`)**：`初级 (scholar)`、`中级 (strategist)`、`高级 (grandmaster)`、`大师 (deity)` 四档；人机开局阶段支持检索匹配定式节点按热度加权随机选着（`grandmaster/deity` 偏向高热度主流变化，`scholar/strategist` 适度扩大采样范围），脱谱后依棋力档位在合法候选中按评估分差加权采样，避免每局走法完全重复。
  - **对局操作（提和 / 认输 / 悔棋 / 长将判负）**：提供 **「向电脑提和 / 双方议和」**（若当前存在单方长将违例直接拒绝提和；若满足无进攻子力死和直接按 `draw-insufficient` 成交；人机模式开局不足 3 回合暂不受理、电脑按 `aiCamp` 评估明显占优 `> +1.2` 婉拒，局势平稳或近限着时握手达成 `draw-agreement`）与 **「认输」**（立即判定 `resign` 终局）；任一方走出构成三次重复的**单方连续长将**时立即自动裁决违例方 **长将判负 (`perpetual-check`)** 且不追加棋钟加秒；人机模式点击底栏 **「悔棋」** 自动连退 2 步直达玩家上一决策回合，本地双人模式单步撤回。
  - **实战着法记录**：实时流式展示已走手数与每手中文纵线记谱，电脑思考时显示「电脑思考中…」。
  - **底部主按钮**：固定展示 **「转入复盘分析」**（有对局着法时显示为 `携带 N 手实战转入复盘分析`，自动携带正确 `basePieces`、`baseTurn` 与红黑双方选手名）。

### 5. 摆子编辑 (`setup`) — 专属摆局工坊
- **居中盘面 + 右侧专属工坊**：隐藏引擎舱、评估柱、席位条与复盘页签，右侧整栏渲染 **「摆子编辑工坊（`SetupWorkbench`）」**。
- **布子拦截、将帅调位与实时棋规校验**：
  - 右侧红/黑双列子力库按传统象棋上限（车马炮士象各2、兵卒5、帅将1）显示剩余可用枚数，非将帅子力放满上限后自动取消选中并置灰禁用；红帅/黑将即使已在盘面仍保持可点击（「`可调位`」状态），亦可直接点击盘面上的红帅或黑将进入调位选中态。
  - **落子即拦截 (`isSetupPiecePlacementAllowed`)**：选中棋子后，棋盘空交点实时提示合法/越界微缩点位与光标反馈；放子时严格校验并拦截越界点位——将/帅仅限己方九宫（`col 3..5`, 红 `row 7..9` / 黑 `row 0..2`，若己方将/帅已在盘面则直接移动至新点位）、士/仕仅限己方九宫 5 个斜点、象/相仅限己方半场 7 个合法象位、兵/卒禁止放于己方底二线及未过河非兵行线（`col 0,2,4,6,8` 以外），越界点击触发哑木双叩与具体拦截提示。
  - **底部实时静态校验 (`validateSetupPosition`)**：持续检查「红帅黑将均在位」「将帅不直接照面」「非当前先行方未已处于被将军状态（防止先行方一动前对方即已受将死局）」；切换先行方时自动清除旧放置警告；未通过时在工坊底部展示详细报错并禁用 **「完成摆子 · 转入复盘分析」** 按钮；点击棋盘已有非将帅棋子直接移除。
- **辅助控制**：支持设定先行方（`红方先行 / 黑方先行`）、`仅留将帅`、`恢复初始棋盘`、实时 FEN 预览与一键复制；棋盘底栏保留 `翻转` 可用，其余步进/悔棋/支招禁用。
- **底部主按钮**：点击 **「完成摆子 · 转入复盘分析」**，校验通过后提交摆出局面并自动切入复盘分析。

## 四、 跨工作空间流转与状态交接机制

系统严格区分「导航切换」与「携带局面转入复盘」两种行为，防止用户误覆盖既有复盘进度：

```text
  [开局研习] ── 点击「携带当前定式转入复盘」 ──┐
  [残局题库] ── 点击「转入复盘分析」         ──┤
  [人机对弈] ── 点击「转入复盘分析」         ──┼──▶ transferPositionToStudy(payload)
  [摆子编辑] ── 点击「完成摆子」             ──┤       1. workspace = 'study'
  [导入/棋谱库] ── 载入 FEN / 对局           ──┘       2. 写入 basePieces / baseTurn / moves / ply / metadata
                                                      3. 清空旧支线与重练状态，rightTab = 'moves'
                                                      4. 设置 isAnalyzing = true，自动持久化至 localStorage

  [复盘分析] ── 点击「去精练 → / 前往开局研习」 ────▶ handleGoToOpeningWorkspace()
                                                      保持复盘会话不覆盖，并在标准起点时携带已走开局进入「开局研习」

  [任意模式] ── 点击顶栏「复盘分析」 ──────────────▶ handleSwitchWorkspace('study')
                                                      从 localStorage 恢复上一次复盘会话（不覆盖原研习进度）
```

> **设计重点**：当用户点击 `BoardNav` 的「回到开局 (`Home`)」或 `currentPly === 0` 时，棋盘恢复的是 `studyBasePieces` 与 `studyBaseTurn`（而非硬编码的 32 子标准开局），因此由摆子、残局、让子实战或 FEN 导入转入复盘后，前后步进跳转始终保持起点一致。

## 五、 棋盘坐标与数据协议约定（后端对接核心）

### 1. 棋盘坐标系 (`Position`)
- **行 (`row`)**：`0 ~ 9`，从上到下递增（标准未翻转视角下：`0~4` 为黑方半场，`5~9` 为红方半场；黑将九宫 `row: 0..2, col: 3..5`，红帅九宫 `row: 7..9, col: 3..5`）。
- **列 (`col`)**：`0 ~ 8`，从左到右递增（对应黑方 `1~9` 路、红方 `九~一` 路）。
- **ICCS 坐标映射（与 UCI/UCCI 引擎对接）**：
  - 列映射：`col 0..8` ↔ `'a'..'i'`
  - 行映射：`row 0..9` ↔ `'9'..'0'`（即 `iccsRank = 9 - row`，例如红方炮二平五 `(7,7)->(7,4)` 对应 `h2e2`）。

### 2. 核心类型契约（见 `src/types/xiangqi.ts`）
- **`Piece`**：`{ id, type: 'general'|'advisor'|'elephant'|'horse'|'chariot'|'cannon'|'soldier', camp: 'red'|'black', row, col }`
- **`MoveNag` & `MoveRecord`**：`MoveNag = '!!' | '!' | '!?' | '?!' | '?' | '??'`；`MoveRecord` 记录每半步（ply）的 `from`、`to`、`captured`、中文记谱 `notation`、红方视角分值 `evalScore`（单位：**兵/子力值**，如 `+1.25`；杀棋用 `mateIn`）、着法评级 `quality ('妙'|'优'|'良'|'缓'|'败')`、人工棋评符号 `nag?: MoveNag`、手写文字批注 `comment?: string`、失误正着建议 `bestAlternative / bestFrom / bestTo`，以及落子后的 `piecesSnapshot`（用于前端 O(1) 跳手回放）。
  - **PGN / 文本批注序列化约定**：标准 PGN 导出内联附带 `MoveNag`（可选 `$1/$2/$3/$4/$5/$6` 标准 PGN NAG 码或内联符号 `!!..!`）与 `{comment}` 花括号注释块；当导出勾选「附带引擎评分与评级」时输出 `{评:quality score | comment}`，未勾选时仅保留纯手写 `{comment}` 与 `nag`；注释正文中的 `{`/`}` 统一转义清洗为 `(`/`)`。
- **`MultiPVLine`**：单条引擎候选主变，含 `multipv`、`depth`、`scoreCp`（**当前前端约定为红方视角分值，单位为分/百分兵折算后的浮点值，如 `+0.45`；若后端引擎返回红黑当前行棋方视角的 centipawn，需统一转换为红方视角并除以 `100` 传入**）、`mate`、`nps (kN/s)`、`hashfull (‰)`、`pvMoves`（中文着法数组）、`firstMove`、`summaryText`。
- **`EngineProfile`**：引擎档案，含 `id`、`name`、`shortName`、`protocol ('UCI'|'UCCI')`、`styleLabel`、`nnueFile`、`sizeMb`、`status ('missing'|'installing'|'ready')`、`installProgress (0..100)`。
- **`GameTerminalState`、`DrawRuleStatus`、`SetupValidationResult` & `MaterialAdvantagePiece`**：
  - `GameTerminalKind`: `'checkmate' | 'stalemate' | 'draw-60moves' | 'draw-repetition' | 'draw-agreement' | 'draw-insufficient' | 'perpetual-check' | 'resign' | 'timeout'`，配合 `winner?: Camp`、`loser?: Camp` 与 `reasonText?: string` 覆盖全部 9 类自然/和棋/违例/认输/超时终局。
  - `DrawRuleStatus`: `{ halfmoveNoCapture, noCaptureRounds, repetitionCount, perpetualCheckCamp, canClaim60MoveDraw, canClaimRepetitionDraw, canClaimInsufficientDraw }`：无吃子半步数 `halfmoveNoCapture` 自动扣减将军手，达 `>= 120`（60 回合）触发限着判和；同一 `positionKey` 重复 `>= 3` 次时结合区间内双方每步是否将军判断 `perpetualCheckCamp`（单方长将时压制重复判和并在 `play` 判负、其他模式提示退回变着）；双方均无 `chariot | horse | cannon | soldier` 时标记 `canClaimInsufficientDraw = true`。
  - `SetupValidationResult`: `{ isValid, reason, hasBothGenerals, generalsFacing, inactiveCampInCheck }`，支撑摆子工作台实时静态合法性校验。
  - `MaterialAdvantagePiece`: `{ type: PieceType, count: number }`，`calculateMaterialAndCaptures` 返回净多子力明细 `redAdvantagePieces` / `blackAdvantagePieces` 供 `PlayerSeatBar` 展示净胜子力微缩圆章。
- **`BoardUserArrow` & `BoardUserCircle` & `BoardAnnotationSnapshot`**：盘面手绘战术标注结构，支持 `BoardAnnotationColor ('gold' | 'jade' | 'crimson' | 'azure')` 配色及起止坐标；`BoardAnnotationSnapshot = { arrows, circles }` 由 `Board` 同步输出至战报 PNG 生成器（`renderBattleReportCanvas`）。
- **`PlayOpponentMode` & 分享直链载荷**：`PlayOpponentMode = 'ai' | 'local-pvp'`；URL 分享直链采用 `#share=` + Base64URL JSON（字段：`v`, `baseFen`, `moves: [fromRow, fromCol, toRow, toCol][]`, `ply`, `flipped`, `meta: { r, b, e, o, res }`）。
- **`ChessClockPresetId` & `ChessClockPreset`**：支持 `'none' | 'blitz-5-3' | 'rapid-10-5' | 'classical-20-10'`，携带 `initialMs` 与 `incrementMs`。
- **`LibraryGameItem` 与 `CompactLibraryMove`**：棋谱库记录除基本元数据外，包含 `category ('master' | 'ancient' | 'user' | 'recent')`、`baseFen` 与压缩步法数组 `movesData: { from, to, evalScore?, quality?, nag?, comment? }[]`，加载时通过 `replayCompactMoves` 全量还原每手历史快照与人工批注；棋谱库弹窗支持分类统计、关键词检索、胜负筛选、4 维排序、「保存当前对局入库」及单局 **一键下载 `.pgn` 棋谱文件**。

### 将军、应将、滑移反馈与 9 类终局视听交互契约
1. **将帅受将与照将射线**：当任一方受将时，受将方将/帅底盘渲染朱红脉冲警戒环，并由 `getCheckingAttackers` 计算所有照将棋子坐标，在动态矢层绘制朱红/鎏金脉动虚线攻击射线（完整支持双将）。
2. **「將軍」非阻塞瞬时书法印章**：触发将军时，棋盘中央浮现约 `1.3s` 朱砂书法印章（`pointer-events: none`，不阻断应将选子），并触发 Web Audio API 中式铜磬双音合成（`playCheckChimeSound`：D5 + A5 金属泛音）。
3. **「应将」严格校验与克制化险反馈**：受将时棋盘仅高亮并允许可解除将军的合法着法；若尝试机械可行但未能应将或自杀送将的落子，触发哑木双叩（`playInvalidWarningSound`）、受将将帅轻摇动画（`animate-illegal-shake`）及 `StatusBar` 短暂提示；成功应将化险后静默收起警示，恢复清脆木音与常规行棋，无多余干扰弹窗。
4. **「絕殺 / 困斃 / 死和 / 長將負 / 和棋 / 认负 / 超时」9 类终局印章与自由查看**：检测到当前行棋方无合法应手（`checkmate / stalemate`）、单方长将（`perpetual-check`）或玩家/裁判触发 `draw-60moves / draw-repetition / draw-agreement / draw-insufficient / resign / timeout` 时，播放中式响铜大锣与金磬收煞合成音效（`playCheckmateGongSound`），在楚河汉界呈现可收起的终局卡片（支持「收起查看棋盘」并由右上角角标随时恢复、底栏步进回顾历史手、以及一键「复盘报告 / 转入复盘分析」与「再来一局 / 重摆此关」）；触发后立即清空 AI 思考定时器并停止计时器。
5. **交互手势与动画防干扰契约**：棋子 FLIP 平滑滑移基于稳定的 `piece.id` 计算前后坐标位移，仅作用于 `transform` 以避免重排；拖拽释放落子瞬间主动跳过该棋子二次 FLIP 补间防回弹闪跳，且交互层所有非棋盘浮动卡片（判和提示条、终局印章卡片）均阻断鼠标/指针事件向棋盘交点热区冒泡。

### 引擎分析调度与前端渲染防阻塞契约（对接真实引擎时保持一致）
- **快速步进防抖与过渡调度**：在连续键盘翻步（`← / →`）或 `850ms` 自动回放期间，引擎分析任务（MultiPV 与威胁雷达）经过 **`120ms` 防抖** + React `useDeferredValue` 低优先级队列调度；当分析目标尚未追平当前最新盘面时，棋盘隐藏旧手推荐箭头以免误导，`EvalBar` 立即回退展示当前着法记录分值（或即时静态分值），保证 60fps 交互响应；真实后端/原生进程对接时同样建议在连续跳步窗口内取消或去抖 `stop` / `go` 指令。
- **三层隔离与精细化 Memo**：棋盘划分为「静态纹理与网格层（含 SVG `feTurbulence` 宣纸肌理与 `contain: layout paint style` 合成隔离）」、「动态箭矢与用户手绘标注层」、「交互落子与 90 格拖拽/右键热区层」，配合全工作台组件 `React.memo` 与稳定回调引用，避免单步落子、右键画线或悬停预览触发整盘与底纹重绘。
