# 象棋X · 前端工作台 (`xiangqix-ui`)

> **象棋X (XiangqiX) v2.4** 专业中国象棋分析与对弈桌面端 UI 工作台。  
> 本仓库为**完整纯前端工程**（React 19 + TypeScript + Tailwind CSS v4 + Vite），内置完整的中国象棋走子规则、无感内联分支推演、棋具考工渲染以及前端模拟引擎/连线/识图交互闭环，可直接独立运行演示，也可无缝对接到 `zpjio/xiangqix` 主客户端工程。

---

## 一、 仓库矩阵与定位说明

| 仓库名称 | 权限建议 | 核心定位与职责边界 |
| :--- | :--- | :--- |
| **`zpjio/xiangqix`** | 主工程 | **完整桌面端应用**：集成 Tauri / Electron 原生壳、Pikafish UCI 进程通信、外部象棋窗口连线抓图、本地图片识别推理及本仓 UI |
| **`zpjio/xiangqix-ui`** *(本仓库)* | 私有 | **2.0 完整前端工作台**：包含全部四大核心工作空间、弹窗套件、主题规范与前端交互状态机，供产品迭代与主工程合入 |
| **`zpjio/xiangqix-craft`** | 公开开源 | **棋具考工与视觉设计展示**：对外公开分享传统棋盘纹理、棋子阴刻工艺与前端视觉探索 |

## 二、 核心功能与 2.0 交互架构

### 1. 四大工作空间（顶栏中区导航）
> 完整交互流转与后端接口对接规范见 [`docs/PRODUCT_INTERACTION_SPEC.md`](./docs/PRODUCT_INTERACTION_SPEC.md)。

- **复盘分析 (`study`)**
  - **引擎分析枢纽**：仅本模式挂载多引擎分析舱与左侧胜率评估柱，支持单个 **「开始分析 / 暂停分析」** 开关，未安装引擎时展示一键下载进度引导。
  - **无感内联分支推演**：在任意历史手直接点击盘面走子或点击右侧候选主变，自动从该手分叉生成内联推演支线，支持一键「升为主线」或「回主谱」，无需切换模式。
  - **连续双栏数据棋谱 (`MoveList`)**：固定表头（`回合 | 红方着法 / 评估 | 黑方着法 / 评估`），每步完整展示 14px 宋体加粗着法、`妙/优/良/缓/败` 质量角标与右对齐等宽分值；空局时提供示范名局、导入与棋谱库快捷引导。
  - **整局复盘报告 (`GameReviewPanel`)**：基于着法质量动态统计红黑精准度、内嵌 SVG 局势演化曲线（`EvalGraph`）、关键失误诊断卡片及一键「**重练此手**」交互闭环。
- **残局题库 (`challenge`)**
  - 隐藏引擎舱与评估柱保持纯净闯关，内置《七星聚会》《野马操田》《千里独行》《顺炮弃马局》等经典古谱；重摆与支招统一由棋盘底栏触发，底部提供「**转入复盘分析**」携带当前局面与试走着法进入深度分析。
- **人机对弈 (`play`)**
  - 隐藏引擎舱与评估柱专注实战，支持传统让子规则（`分先` / `让先` / `让左马` / `让双马`）与四档电脑棋力切换（`初级` / `中级` / `高级` / `大师`），底部提供「**转入复盘分析**」携带让子开局与全部实战着法无缝复盘。
- **摆子编辑 (`setup`)**
  - 右侧专属 **「摆子编辑工坊」(`SetupWorkbench`)** 整合红黑双列子力配额限额、将帅完整性校验、先行方设定与实时 FEN 复制，点击「**完成摆子 · 转入复盘分析**」后直接以自定义局面启动分析。

### 2. 多引擎分析舱与双擎并行对比 (`EnginePanel`)
- **多引擎库与主引擎快速切换 (`engines: EngineProfile[]`)**：
  - 预置 **`皮卡鱼 Pikafish 2026 [UCI·均衡全能]`**、**`旋风 Cyclone v12 [UCI·中路强攻]`**、**`天机 XQMS Pro 3.26 [UCCI·阵地绵密]`** 三大主流引擎，并支持导入自定义本地引擎。
  - 当所选引擎未安装时，自动展示对应引擎的一键下载安装引导卡片（显示所需 NNUE 权重文件名与安装进度条）。
- **双擎并行对比模式 (`compareMode` / 快捷键 `C`)**：
  - **共识与分歧自动诊断横幅**：实时比对主副引擎第一主变着法，自动给出 **`✓ 双擎共识：一致首推 [着法]（分差 ΔX.XX）`** 或 **`⚡ 双擎分歧：[主擎]主推 [着法A] · [副擎]主推 [着法B]`**。
  - **主/副引擎双色对照与一键互换**：主引擎采用翡翠绿（`#10B981`）、副引擎采用天青蓝（`#3B82F6`），支持卡片内一键互换主副引擎、盘面双色箭头叠加（共识时自动合并为 `[双擎共识]` 箭头并错位排布标签防遮挡）及左侧胜率评估柱副引擎刻度线对照。
- **实时多主变 (`MultiPV`) 与威胁雷达 (`Threat Radar`)**：
  - 支持 1~3 条候选变例实时展示，鼠标悬停候选变例可在棋盘上渲染半透明幽灵预览箭头，点击直接落子推演。
  - 开启「威胁雷达」后，在盘面用红色虚线箭头标出对方下一步最具威胁的攻着。

### 3. 全局工具栏与弹窗套件 (`DialogsModalSuite`)
- **棋谱库 (`library`)**：支持「全部棋谱 / ★ 我的收藏 / 现代名局 / 古谱名局」分类筛选与关键词搜索，与主界面棋谱顶部的「收藏」按钮实时双向同步。
- **导入 / 棋谱 (`fen-pgn`)**：
  - **FEN / PGN 页签**：支持 FEN 局面编码与完整 PGN 棋谱文本的双向导入、复制导出及格式合法性校验。
  - **图片识别局面页签**：极简一屏设计，支持点击选图、拖入或直接 `Ctrl+V` 粘贴剪贴板截图，选择红先/黑先后一键载入棋盘。
- **外部平台连线 (`connect`)**：
  - 选择外部窗口（天天象棋 / JJ象棋 / 模拟器）连接后，**直接复用「复盘分析」工作台**，在棋谱上方显示绿色同步状态条，避免冗余页面切换。
- **单页设置中心 (`settings`)**：
  - 集成「本地引擎安装状态管理 + 界面深浅主题 + 棋子简繁字形 + 三款棋盘材质 + 三款棋子工艺 + MultiPV/深度档位 + 界面字号 + 音效开关 + 底部关于与检查更新」。

## 四、 视觉与主题设计规范（供前端开发参考）

### 1. 现代中性壳层 + 传统棋具焦点
- **深色模式 (`html[data-theme="dark"]`)**：采用现代中性深灰画布（`#121316`）与面板（`#181A1F`），摒弃全屏棕红底色，突出中央木纹/朱漆/青瓷棋盘。
- **浅色模式 (`html[data-theme="light"]`)**：采用清爽中性浅灰画布（`#F2F4F7`）与纯白面板（`#FFFFFF`）。
- **棋盘尺寸自适应**：棋盘容器采用 `w-[clamp(430px,calc((100vh-228px)*0.89),620px)]`，根据屏幕高度动态放大（最高达 `620px` 宽），同时确保一屏完整容纳不出现纵向滚动条。

### 2. 全局 5 级语义按钮类名（定义于 `src/index.css`）
新增或修改按钮时，请统一使用以下语义类名，自动适配深/浅双主题对比度：
- `.xq-btn-primary`：主操作按钮（弹窗确认、载入棋盘、保存、一键安装、支招、重练此手）
- `.xq-btn-secondary`：次级常规按钮（顶栏工具按钮、取消、复制、翻转、悔棋）
- `.xq-btn-option` / `.xq-btn-option-active`：分段选择器与选项卡按钮（设置项、让子、难度、分类筛选）
- `.xq-btn-engine-on`：引擎运行中 / 外部连线激活态按钮（翡翠绿）
- `.xq-btn-danger`：警示 / 断开连线 / 删除按钮（朱砂红）

## 五、 合入 `zpjio/xiangqix` 主工程对接指南（交接重点）

> 详细的 API 入参/出参结构、ICCS 坐标换算、红方视角分值约定及跨模式流转协议，请直接查阅 [`docs/PRODUCT_INTERACTION_SPEC.md`](./docs/PRODUCT_INTERACTION_SPEC.md)。

将本仓库合入主客户端工程时，`src/components/` 与 `src/index.css` 可 **100% 原样保留**，仅需将 `src/App.tsx` 与弹窗识图回调中的前端模拟逻辑替换为真实原生/后端接口：

1. **本地引擎检测与安装 (`engines` & `handleInstallEngine`)**：启动时检查本地引擎与 NNUE 权重，支持通过回调实时回传 `installProgress` 与 `status`。
2. **UCI / UCCI 引擎实时分析流 (`multiPvData`、`secondaryMultiPvData` & `threatArrow`)**：将 `generateSimulatedMultiPV` 与 `generateOpponentThreatArrow` 替换为真实引擎分析流（支持单擎与双擎并行对比）。
3. **人机对弈应手 (`executeMoveOnBoard` 中的 `play` 分支)**：按棋力档位调用真实引擎返回黑方应手坐标。
4. **图片识别导入 (`DialogsModalSuite` 中的 `image` 页签)**：将上传或粘贴的图片 `File / Blob` 传给本地/后端识盘模型，获取 FEN 后调用 `onApplyFen(fen)`。
5. **外部象棋平台连线同步 (`connectState` & `handleSyncNextExternalMove`)**：外部窗口抓图监听到新着法后调用 `executeMoveOnBoard(from, to)` 自动同步进复盘棋谱。
